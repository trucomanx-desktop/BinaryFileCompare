# binary-file-compare

Binary file compare


## Install from PYPI

The homepage in pipy is https://pypi.org/project/binary_file_compare/

```bash
pip install --upgrade binary_file_compare
```

Using:

```bash
binary-file-compare
```

## Install from source
Installing `binary-file-compare` program

```bash
git clone https://github.com/trucomanx-desktop/BinaryFileCompare.git
cd BinaryFileCompare
pip install -r requirements.txt
cd src
python -m build
pip install dist/binary_file_compare-*.tar.gz
```
Using:

```bash
binary-file-compare
```

## Uninstall

```bash
pip uninstall binary_file_compare
```
